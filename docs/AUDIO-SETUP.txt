HDR Bridge para Windows 11 x64 com VB-CABLE

Extraia todos os arquivos deste ZIP antes de abrir os executáveis.

Se ouvir o som duas vezes, abra Configurações > Sistema > Som > Mixer de volume
com o áudio do Bridge ativo e silencie somente HDR Bridge em Aplicativos.
Confirme que quem assiste ainda ouve o som. Se o áudio da transmissão também
sumir, encaminhe o som pelo VB-CABLE seguindo os passos abaixo.

1. Se o CABLE Input ainda não estiver instalado, abra a pasta VB-CABLE
   deste ZIP ou baixe o instalador oficial em https://vb-audio.com/Cable/
   Extraia o instalador se necessário. Clique com o botão direito em
   VBCABLE_Setup_x64.exe e escolha Executar como administrador.
   Clique em Install Driver e reinicie o Windows.
2. Abra HdrBridge.exe e clique em Áudio. Selecione a fonte desejada,
   escolha CABLE Input como destino e clique em Aplicar áudio.
3. Na plataforma de transmissão, selecione CABLE Output como entrada
   de áudio. O som encaminhado vai para o cabo e você ouve o som original
   nos fones.

Use a instalação do driver apenas uma vez. Se você só precisa de vídeo,
pode abrir o HDR Bridge diretamente. A instalação do VB-CABLE é opcional.
